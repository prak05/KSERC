"Vibe" & Design System Documentation Since "vibe coding" relies heavily on the AI understanding your aesthetic intent, you need precise visual references to prevent generic output.
Design System / Style Guide: A document defining your color palette (hex codes), typography (font families, sizes), spacing standards (e.g., Tailwind classes), and component styles (button radiuses, shadows). Providing this to the AI ensures consistent UI generation.
Visual References (Mood Board): A collection of screenshots or URLs of existing websites that match the "vibe" you want. You will often upload these to the AI to ground its visual generation.
User Flow / Wireframes: Simple low-fidelity sketches or diagrams showing how screens connect. AI is great at building single pages but often struggles with complex navigation flows without explicit guidance.
Technical Architecture & Logic The AI acts as a junior developer; it needs a senior architect (you) to define the structure so it doesn't write "spaghetti code."
Tech Stack & Constraints Document: A brief file listing your non-negotiable technologies (e.g., "Next.js 14, Supabase, Tailwind CSS, Shadcn UI"). This is often used as a "System Prompt" or "Context" file in tools like Cursor to keep the AI aligned.
Database Schema (ERD): An Entity-Relationship Diagram or a text-based schema definition (e.g., a schema.sql or schema.prisma file). Defining your data structure before asking the AI to build features prevents it from hallucinating conflicting data models.
API Contract / Interface Spec: If you are connecting to external services or separating frontend/backend, document the expected JSON request/response format.
AI Context & Prompt Engineering These are specific to building with AI and building for AI features.
Context/Memory File: A master document (often a Markdown file in your repo) that summarizes the project status, current features, and "lessons learned" (e.g., "Always use 'toast' for errors, never 'alert'"). You feed this to the AI periodically to maintain continuity across sessions.
Prompt Library: A document storing the successful prompts you used to generate core features. This allows you to iterate or rebuild parts of the app reproducibly.
AI Behavior Guidelines (System Prompt): If your app features an AI (e.g., a chatbot), you need a document defining its persona, tone, boundaries (what it shouldn't say), and specific instructions for how it handles user data.
Compliance & Quality Assurance Vibe coding is fast, which means bugs and security holes can creep in faster, too.
Edge Case Checklist: AI often codes for the "happy path." Keep a list of edge cases (e.g., "User has no internet," "Input is too long," "API is down") to explicitly prompt the AI to handle them.
Security & Data Privacy Policy: A document outlining how user data is handled, especially if you are sending user inputs to LLMs (OpenAI/Anthropic). You may need this for legal compliance (GDPR/CCPA) and to configure your AI provider's data retention settings.
Test Plan: A simple list of critical user journeys to manually test, as AI-generated unit tests can sometimes pass even when the feature feels "off" to a human.             if page_text:  # Only add if text was found (not a blank/image page)
                extracted_text += f"\n--- Page {page_num + 1} ---\n"  # Page marker
                extracted_text += page_text  # Add the page text
            
            tables = page.extract_tables()  # Extract any data tables on this page
            for table in tables:  # Loop through each table found
                extracted_text += "\n[TABLE DATA]:\n"  # Mark it as a table
                for row in table:  # Loop through each row in the table
                    if row:  # Skip empty rows
                        # Join cells with | separator for clarity
                        extracted_text += " | ".join([str(cell or "") for cell in row]) + "\n"
    
    return extracted_text  # Return all extracted content as one string

# ─── Helper: Calculate revenue gap ────────────────────────────────────────
def calculate_revenue_gap(approved_arr, actual_revenue):
    """
    Core truing-up formula: Revenue Gap = Approved ARR - Actual Revenue
    Positive = Gap (licensee owed money)
    Negative = Surplus (licensee collected more than approved)
    All values in ₹ Lakh.
    """
    gap = approved_arr - actual_revenue  # Subtract actual from approved
    
    outcome = "GAP" if gap > 0 else "SURPLUS"  # Label the result
    
    # Check if result is within historical bounds (sanity check)
    is_anomaly = gap > 64.72 or gap < -280.42  # Outside all known KSERC cases
    
    return {
        "gap_amount": round(gap, 2),       # Round to 2 decimal places
        "outcome": outcome,                 # GAP or SURPLUS label
        "is_anomaly": is_anomaly,           # Flag if outside historical range
        "message": f"₹{abs(gap):.2f} Lakh {outcome}"  # Human-readable summary
    }

@app.route("/analyze", methods=["POST"])
def analyze():
    """
    Receives uploaded PDF, extracts text, sends to Gemini AI for analysis.
    Returns AI analysis as JSON.
    """
    # Check that a file was actually included in the request
    if "document" not in request.files:
        return jsonify({"error": "No file uploaded. Please select a PDF."}), 400
    
    file = request.files["document"]  # Get the uploaded file object
    licensee = request.form.get("licensee", "Unknown Licensee")  # Get licensee name
    year = request.form.get("year", "2024-25")  # Get financial year
    
    # Check file has a name (not empty selection)
    if file.filename == "":
        return jsonify({"error": "No file selected."}), 400
    
    # Validate file type
    if not allowed_file(file.filename):
        return jsonify({"error": "Invalid file type. Only PDF and Excel files accepted."}), 400
    
    # Secure the filename to prevent path traversal attacks
    filename = secure_filename(file.filename)
    
    # Save uploaded file to uploads directory
    upload_path = os.path.join(app.config["UPLOAD_FOLDER"], filename)
    os.makedirs(app.config["UPLOAD_FOLDER"], exist_ok=True)  # Create folder if needed
    file.save(upload_path)  # Save the file
    
    # Extract text from the saved PDF
    try:
        pdf_text = extract_pdf_text(upload_path)  # Extract all text and tables
    except Exception as e:
        return jsonify({"error": f"Could not read PDF: {str(e)}. Ensure file is not password-protected."}), 400
    
    # Build the analysis prompt for Gemini
    analysis_prompt = f"""
Perform a complete KSERC Truing-Up analysis for:
- Licensee: {licensee}
- Financial Year: {year}

DOCUMENT CONTENT:
{pdf_text[:8000]}

REQUIRED ANALYSIS — Address each point:
1. REVENUE GAP / SURPLUS: Identify Approved ARR and Actual Revenue. Compute gap/surplus with formula.
2. LINE-ITEM VALIDATION: For each cost item found, state: Claimed | Approved | Disallowed | Reason
3. PERENNIAL REJECTIONS: Flag any Section 3(1) duty or CSR expenses found. Approve ₹0.
4. O&M NORMATIVE CHECK: Check if Employee Cost, R&M, A&G are within normative caps.
5. DISTRIBUTION LOSS: If found, compare against target. Calculate efficiency gain if applicable.
6. ANOMALIES: Flag any unusual figures vs historical benchmarks.
7. FINAL DETERMINATION: State the approved Revenue Gap or Surplus in ₹ Lakh.
8. REGULATORY CITATIONS: Cite the specific regulation or past order for each decision.

Format your response with clear section headers. Use ₹ Lakh for all values.
"""
    
    # Send to Gemini AI for analysis
    try:
        response = model.generate_content(analysis_prompt)  # Call Gemini API
        ai_analysis = response.text  # Extract the text response
    except Exception as e:
        return jsonify({"error": f"AI analysis failed: {str(e)}. Check your API key."}), 500
    
    # Return the analysis result as JSON
    return jsonify({
        "success": True,
        "licensee": licensee,          # Echo back the licensee name
        "year": year,                   # Echo back the financial year
        "filename": filename,           # The uploaded file name
        "analysis": ai_analysis,        # The full AI analysis text
        "pages_extracted": pdf_text.count("--- Page"),  # Number of pages processed
    })
